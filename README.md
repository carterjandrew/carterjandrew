# Projects

Here is a small list of my favorite projects I've contributed to:

## Operating Systems and Development
### [Secretspec](https://secretspec.dev/)

Secretspec helps make it harder for codebases to get hacked, and easier for developers to use good secret keeping practices. 

I built and maintain the interface between Secretspec and Setec: a tailscale based secrets manager. 
### [NixOS](https://nixos.org/)

I have contributed and maintain a number of packages for NixOS, some on the nixpkgs list and some just as independent flakes. These include:
